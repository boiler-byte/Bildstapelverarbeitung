    Hilfe

    1. Bilder hinzufügen

    • Auf Bilder hinzufügen oben in der Leiste klicken.
    • Oder Bilddateien direkt in das Fenster ziehen (die ganze Seite wird zur Drop-Zone).
    • Oder aus der Zwischenablage einfügen: Strg+V (bzw. Cmd+V).

    2. Einzelbild bearbeiten

    • Auf einer Kachel auf Bearbeiten klicken.
    • Werkzeuge: Zuschneiden, Rotation, Farbe nach Alpha, Resize.
    • Schritte werden in Reihenfolge angewandt; der letzte lässt sich mit Letzten Schritt entfernen zurücknehmen.
    • Zum Zuschneiden: im Bild ein Rechteck aufziehen oder Werte eintippen, dann Zuschneiden anwenden.
    • Der Dateiname oben lässt sich anklicken und ändern.
    • Übernehmen speichert die Schritte, Abbrechen verwirft sie.

    3. Bild zerlegen (Gitter)

    • Im Editor auf den Tab Zerlegen wechseln.
    • Zellgröße, Spalten/Zeilen und Offsets festlegen.
    • Zerlegen ersetzt das Original durch die einzelnen Teilbilder im Stapel.

    4. Ops auf alle Bilder anwenden

    • Ein Bild wie gewünscht bearbeiten und übernehmen.
    • Im Export-Panel auf Editor-Ops auf gesamten Stapel anwenden klicken.
    • Die Schritte des zuletzt bearbeiteten Bildes werden dann auf alle anderen übertragen.

    5. Exportieren

    • Im Export-Panel Format (JPEG, PNG, WebP, SVG) wählen.
    • Bei JPEG/WebP die Qualität, bei SVG die Alpha-Schwelle anpassen.
    • Optional Suffix und zusätzliche Zielbreiten angeben — dann werden nur diese Versionen exportiert.
    • ZIP exportieren lädt alle bearbeiteten Bilder gesammelt als ZIP herunter.
